# Local Example

## Getting Started

To run the application locally, follow these steps:

1. **Clone the repository**

   ```bash
   git clone https://github.com/tokamak-network/ton-staking-sdk-examples.git
   ```

2. **Navigate to the project directory**

   ```bash
   cd local-sample-1
   ```

3. **Install dependencies**

   ```bash
   pnpm i
   ```

4. **Run the test scripts**

   ```bash
   node tests/mainnet.test.js
   # or
   node tests/sepolia.test.js
   ```
